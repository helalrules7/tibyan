الفحص

    —

    نص القرآن من بيانات تطبيق تبيان كما هي (نص مجمع الملك فهد، الإصدار 2.0، بخط المجمع غير معدل). التوقيت منشور برخصة CC BY 4.0 مع نسبة مصادره المذكورة في docs/TIMING.md.

    اقترح التعديل على GitHub

    2. افتح الملف في محرر GitHub سجّل الدخول إلى GitHub إن طُلب منك؛ سيعرض عليك إنشاء نسخة (fork) تلقائيا.
    3. في محرر GitHub: حدد كل النص (Ctrl/⌘+A) والصق (Ctrl/⌘+V).
    4. اضغط الزر الأخضر Commit changes… ثم Propose changes. في الصفحة التالية اضغط Create pull request، واكتب ما سمعته ولماذا عدّلت، ثم Create pull request مرة أخرى.
      عنوان مقترح:

    سيفحص GitHub التعديل تلقائيا، ويراجعه أحد المشرفين بالاستماع قبل دمجه. بعد الدمج يصل التوقيت الجديد إلى التطبيق خلال ١٢ ساعة تقريبا. ليس لديك حساب GitHub؟ أنشئه مجانا من github.com/signup، أو نزّل الملف. التفاصيل في الدليل.

    English
    1. Copy the new file.
    2. Open it in GitHub's editor (sign in; GitHub offers to fork the repository).
    3. Select all, paste, then Commit changes… → Propose changes → Create pull request. Say what you heard and why you changed it.

    طريقة العمل

    1. اختر القارئ والسورة، ثم شغّل التلاوة. الكلمة المسموعة تُظلَّل.
    2. إن رأيت التظليل يسبق الصوت أو يتأخر عنه: اختر الكلمة (بالنقر عليها) وعدّل بدايتها أو نهايتها بالسحب على الموجة، أو بأزرار ±١٠ و±٥٠ مللي ثانية، أو «= الآن» أثناء التشغيل.
    3. للكلمات الكثيرة: «وضع النقر» — اضغط مسافة عند بداية كل كلمة وأنت تسمع، وخفض السرعة إن احتجت.
    4. كرر الكلمة أو الآية لتسمع الحد مرات. ثم «اقترح التعديل».
